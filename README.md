Мощный и современный комплекс для комплексной оптимизации операционной системы Windows и игры Rust. Позволяет значительно повысить стабильность FPS, минимизировать задержку ввода (input lag), устранить микрофризы и статтеры, а также удобно управлять графическими настройками, биндами, параметрами запуска и кодами камер видеонаблюдения (CCTV).

## Возможности

### Оптимизация системы и задержек
* **Автоматический CPU Affinity**: интеллектуальное определение топологии процессора (P-ядра / E-ядра Intel, CCD с 3D V-Cache на AMD Ryzen) и привязка процесса `RustClient.exe` к наиболее производительным ядрам без задействования энергоэффективных или медленных потоков.
* **Автонастройка буфера сборщика мусора (GC Buffer)**: автоматический расчет оптимального значения `gc.buffer` под установленный объем оперативной памяти, что предотвращает фризы во время периодической сборки мусора Unity.
* **Твики Windows для киберспорта**:
  * **Отключение HAGS**: деактивация Hardware-accelerated GPU Scheduling (`HwSchMode`) для уменьшения задержки кадров и повышения стабильности времени кадра (frametime).
  * **Отключение HVCI**: выключение изоляции ядра (Memory Integrity), вызывающей заметные просадки FPS на большинстве конфигураций.
  * **Отключение PCI Express LPM (ASPM)**: устранение энергосберегающих состояний шины PCIe, провоцирующих задержки видеокарты.
  * **Отключение Xbox Game Bar и GameDVR**: исключение фонового оверлея и захвата кадров.
  * **Схема электропитания**: активация высокопроизводительного плана электропитания с разблокировкой парковки ядер (core unparking).
  * **Оптимизация файла подкачки**: интеллектуальный подбор размера pagefile под объем вашей RAM.
  * **Службы Windows**: отключение лишних фоновых служб Windows по проверенным и безопасным профилям.

### Настройки Rust и графики
* **Готовые пресеты графики**: мгновенное переключение между соревновательными, сбалансированными и ультра-FPS пресетами.
* **Тонкая настройка визуала**: детальное управление дальностью прорисовки, качеством теней, освещением, фильтрацией текстур и эффектами постобработки.
* **Растянутое разрешение (Screen Stretch)**: поддержка и автоматизация кастомных соотношений сторон (4:3, 16:10) для более широких моделей противников и буста частоты кадров.
* **Параметры запуска Steam**: автоматическое формирование оптимальных аргументов командной строки (`-high`, `-maxMem`, настройки рендера).
* **Менеджер биндов**: удобное создание и редактирование биндов на клавиатуру и мышь с сохранением в `keys.cfg`.

### Инструменты и утилиты
* **Каталог камер CCTV**: полный встроенный справочник кодов камер для всех монументов (Нефтяные вышки, Аэродром, Космодром, Сфера, Город бандитов и др.) с возможностью копирования в буфер в один клик.
* **Система резервных копий и отката**: перед применением любых твиков создаётся снимок состояния реестра и конфигураций, позволяя в один клик вернуть систему и игру к первоначальному виду.

## Безопасность

* **100% безопасно для Easy Anti-Cheat (EAC)**.
* Утилита не внедряет DLL в память процесса `RustClient.exe` и не модифицирует файлы игры.
* Все применяемые оптимизации — это официальные параметры движка/игры (`client.cfg`, `keys.cfg`, launch options) и стандартные системные параметры реестра Windows.

## Требования

* Windows 10 (1909+) или Windows 11 (64-bit)
* [.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)
* [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (встроено в современные версии Windows)
* Запуск с правами Администратора (необходимо для применения системных настроек)

## Установка и запуск

1. Скачайте свежий архив `RustOptimizer_Portable.zip` со страницы [Releases](https://github.com/KreziBro/RustOptimizer/releases) (или через кнопку **Code** ➔ **Download ZIP**).
2. Распакуйте архив в любую удобную папку.
3. Запустите `RustOptimizer.exe` от имени администратора.

## Сборка из исходников

```bash
# Клонирование репозитория
git clone https://github.com/KreziBro/RustOptimizer.git
cd RustOptimizer

# Сборка проекта
dotnet build RustOptimizer.sln -c Release
```

Для сборки самодостаточного (self-contained) портативного пакета:

```bash
dotnet publish RustOptimizerCore.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false
```

## Архитектура и стек

* **Ядро**: C# 12 / .NET 8 (WPF)
* **Интерфейс**: WebView2 с современным SPA (Vue 3, адаптивный CSS, анимации, тёмная тема)
* **Аппаратное взаимодействие**: `Mixaill.HwInfo.D3DKMT` (Win32 D3DKMT interop) для мониторинга видеоадаптеров и управления HAGS
* **Бекапы**: атомарная сериализация снимков реестра и файлов конфигураций в JSON
